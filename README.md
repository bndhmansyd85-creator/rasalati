# رسالتي V6
نسخة تطويرية للجوال بواجهة PWA وخادم Node.js/WebSocket.
الجديد: صور + رسائل صوتية من الميكروفون + ملف شخصي + نبذة + رسائل فورية + قراءة + مؤشر الكتابة + حفظ دائم على الخادم.
التشغيل: npm install ثم npm start.
ملاحظة: الإشعارات الخلفية الحقيقية، SMS، المجموعات والمكالمات وتشفير الطرفين تحتاج خدمات إنتاجية إضافية.
